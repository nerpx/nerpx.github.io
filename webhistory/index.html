Summary

Over the past few decades, the web has evolved significantly, going from just a simple text layout to advanced styling, and then to more interactive and useful applications.

Tim Berners-Lee, the inventor of the World Wide Web, created HTML in 1991.

Web History Timeline.

  • 1991 - HTML was created by Tim Berners-Lee
  • 1996 - CSS was created by Hakon Wium Lie
  • 1995 - JavaScript was created by Brendan Eich
  • 1998 - HTML 4.01 was released
  • 1999 - CSS 2.1 was released
  • 2000 - JavaScript 1.5 was released
  • 2004 - HTML5 was released
  • 2005 - CSS3 was released
  • 2009 - JavaScript ES5 was released
  • 2015 - JavaScript ES6 was released
  • 2020 - JavaScript ES11 was released
  • 2021 - JavaScript ES12 was released
  • 2022 - JavaScript ES13 was released
